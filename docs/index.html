What it does

Three benches that share one idea: show the step.

01

Bases, linked

Decimal, hex, binary and octal are four views of one number. Type into any of them and the other three follow, with no reload. Any base from 2 to 36, and the legal digit strip printed beside it.

02

Units, with the factor

Length, mass, data and time carry their factor in the working line. Temperature is affine, so it gets its own formula instead of a factor. KB and KiB stay apart, because they are different units.

03

Timezones, with the rollover

Fixed offsets, stated as fixed. The day change is said out loud rather than swallowed: 01:00 IST is 19:30 UTC the previous day.

What it refuses to do

It would rather say nothing than say something plausible.

  • ×Not a scientific calculator. It converts, and it shows how. Anything else is a different tool.
  • ×No invented answers. An illegal digit, an unknown unit, a length converted to a mass, or 0x on base 10 each produce a sentence saying what is wrong — not a number that looks right.
  • ×No network at any point. No fetch, no CDN, no font service, no analytics. The page carries everything it needs.
  • ×No account, no sync. The conversion log lives in this browser's storage and leaves only when you export it as CSV.

The engine is docs/play/basebench.js and the page is a view over it, so testing the engine tests what the app does. Each assertion was checked to bite: five mutations of the engine — lowercase digits, the day rollover removed, the - 32 dropped from Fahrenheit, the prefix check disabled, the digits reversed — each fail between one and nine assertions.

Run it

Two files and a browser.

git clone https://github.com/drsamonline/base-bench
open docs/play/index.html      # the whole app
node test-node.js              # 116 assertions, no installs

The kits the app uses — web-kit.js for storage and theme, export-kit.js for the CSV — sit next to it in docs/play/, so the bench works from a USB stick, from file:// and from Pages with no server.
